# jackpro-release

JACKPRO 插件的**更新发布仓库**。

## 目录内容

- `package.json`：`version` 字段代表最新版本号，插件据此判断是否有新版本。
- `jackpro-<版本>.vsix`：对应版本的插件安装包，文件名带版本号便于自动挑选最新包。

## 发布新版本流程

1. 提高 `package.json` 中的 `version`（如 `1.0.60`）。
2. 把新的 `jackpro-1.0.60.vsix` 放入本仓库根目录。
3. `git add . && git commit -m "release 1.0.60" && git push`。

客户端插件（侧边栏「自动更新 (Git 远程)」填入本仓库地址并开启自动更新）会在检查时：
克隆/拉取本仓库 → 比对 `package.json` 的 `version` → 若更高则安装根目录中版本号最高的 `.vsix` → 提示重启生效。
